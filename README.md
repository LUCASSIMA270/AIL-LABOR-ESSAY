# AIL-LABOR-ESSAY
How Different Uses of AI Shape Labor Demand: Evidence from France
Overview

This repository contains the data and replication programs for the research paper "How Different Uses of AI Shape Labor Demand: Evidence from France", authored by Philippe Aghion, Simon Bunel, Xavier Jaravel, Thomas Mikaelsen, Alexandra Roulet, and Jakob Søgaard.

The project analyzes how the adoption of artificial intelligence (AI) impacts labor demand in French firms, using matched employer-employee data and specialized surveys.
Repository Structure

The code is organized to process raw data through to the final estimation results:

    data/code/: Contains all scripts for data processing and analysis.

        1_*: Cleaning of initial datasets.

        2_*: Merging the cleaned datasets.

        3_*: Generation of descriptive statistics.

        4_*: Production of estimation results and main regressions.

        5_*: Cleanup scripts to remove temporary datasets.

    data/sources/: Includes some publicly available datasets, such as AI exposure measures based on Bergeaud (2024).

    figz/: Output directory for figures generated by the analysis (e.g., figure1.pdf).

    report/: Contains the main documentation, including the project essay and the original replication guide.

Data Sources

The analysis relies on three primary data sources:

    BTS: Matched employer-employee data describing job positions and individual characteristics.

    BIC-IS: Firm-level tax reports and balance sheets provided by the French fiscal administration.

    ICT Survey: European survey on the use of information and communication technologies in businesses.

Note: Access to confidential data (BTS, BIC-IS, ICT) is restricted and provided via the CASD (Secure Remote Access Device).
Requirements

To replicate the results, the following software versions were used:

    Stata: version 17.0

    R: version 4.3.1

    SAS: version 9.4

Expected execution time for the full pipeline is approximately 6 to 8 hours, requiring between 2 GB and 25 GB of storage space.
Usage

    Ensure all datasets are placed in the appropriate data/ directories.

    Open data/code/0_main.do in Stata.

    Update the file path at the beginning of the script to match your local environment.

    Run 0_main.do to execute the entire cleaning, merging, and estimation process.
